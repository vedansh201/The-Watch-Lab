# The Watch Lab

The Watch Lab is a small interactive website where you can build watches using different elements.
Start with a few basic elements, combine them to discover new ones, and use the elements you've 
unlocked to create your own watches.

## Features

1. Build a watch by assigning elements to different parts of it.
2. Combine elements to discover new elements.
3. Discover special watch combinations.
4. Your unlocked elements and created watches are saved in your browser.
5. Each watch has its own combination of case, dial, hands, strap, and special effect.
6. A live clock shows the current time on your created watches.
7. An archive page keeps track of your discovered elements, combinations, and watches.

## How I built it

- HTML for the structure of the website.
- CSS for the design, animations, layouts, and themes.
- JavaScript for the watch builder, element combinations, live clocks, and saving progress.
- JSON for storing the elements and discovery combinations.
- SVG icons for the different elements.
- `localStorage` to save progress directly in the browser.
